# سامانه آماد و پشتیبانی – پایگاه شهید صیاد شیرازی

نسخهٔ ۵٫۰٫۱ برای ساخت در Android آماده‌سازی شده است و برای استفاده با یک گوشی سرور و چند گوشی کاربر طراحی شده است.

## امکانات این نسخه
- عنوان سامانه و پایگاه در صفحه ورود
- نمایش نمایش تاریخ و ساعت
- ورود با نام کاربری لاتین و نقش مدیر/کاربر
- مدیر پیش‌فرض: `admin` با گذرواژهٔ اولیه `Admin1234` (حتماً پیش از بهره‌برداری تغییر دهید)
- تغییر و بازنشانی گذرواژهٔ کاربران و ذخیرهٔ گذرواژه به‌صورت هش‌شده
- سرور داخلی با HTTP روی درگاه ۸۷۶۵ (بدون رمزنگاری؛ فقط برای آزمایش در شبکهٔ مورد اعتماد)
- اتصال چند گوشی روی یک شبکه به گوشی سرور
- پخش نوحه به ترتیب ورود؛ مدیریت نوحه فقط برای مدیر
- ثبت تعمیرات و تحویل/عودت همراه تاریخ و ساعت دقیق
- خروجی Word و PDF در پوشه خصوصی برنامه
- قلم فارسی Noto Naskh Arabic

## Build فقط با گوشی
1. این پوشه را در GitHub repository قرار دهید.
2. فایل `.github/workflows/build_apk.yml` را نیز حفظ کنید.
3. در GitHub وارد Actions شوید و workflow با نام `Build Android APK` را اجرا کنید.
4. پس از موفقیت، از بخش Artifacts فایل `amad-support-apk` را دریافت کنید.

## نکتهٔ شبکه
گوشی سرور و سه گوشی کاربر باید روی یک شبکه قابل دسترسی باشند. در صفحه «تنظیمات سرور» آدرس IP و پورت 8765 نمایش داده می‌شود. روی گوشی‌های دیگر همان آدرس را وارد کنید.
